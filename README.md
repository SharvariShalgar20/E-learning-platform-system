# 🎓 E-Learning Platform (Java Swing)

This is a simple **E-Learning Platform** built using **Java Swing**.  
It provides a GUI-based dashboard for students to:

- 🔑 Login/Register with Name & Roll No
- 📚 Add Courses with duration
- 🎥 View course-related videos from local folders
- 📝 Take a Java OOPs Test (MCQs)
- 📊 Track Progress with a progress bar
- 🧾 View Course History and Results

---

## 🚀 How to Run
1. Make sure you have **Java (JDK 8 or later)** installed.
2. Save the code as `ELearningPlatform.java`.
3. Compile the program:
   ```bash
   javac ELearningPlatform.java
4.Run the program:
   java ELearningPlatform

---

## 📸 Note about Images

The buttons on the dashboard use icons (e.g., add_course.png, see_progress.png etc.).

If the images are not visible, make sure to place the .png files in the same folder as ELearningPlatform.java (or inside the compiled folder with .class files).

You can also replace them with your own icons.

---

## 🛠 Features Implemented

-User login and validation

-Dashboard with 6 options (Add Course, See Progress, View Videos, Take Test, See Result, View History)

-Course management (stored in memory using ArrayList)

-Progress tracking system (updates as you add courses, watch videos, and take tests)

-Test window with 10 multiple-choice questions

-Result window showing student details and score

-Course history display
